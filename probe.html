Settings


  
Key storage: your key is saved only in this browser's localStorage and is sent
    only to the selected provider's API when solving. Anyone using this browser profile could read a
    saved key, so use Clear Key on shared devices.

  
Privacy: camera frames stay on this device. A snapshot leaves the phone only
    when sent to the selected provider to answer a question. No analytics, no other network calls.

  
Hosting: phone cameras require a secure page. Host this file over HTTPS
    (GitHub Pages, Vercel) and open the https:// link.

  






  
Vision Quiz Solver

  
Point the back camera at a test screen. When the screen changes and settles,
    the app reads the new question and speaks the answer letter out loud.

  
1. Open Settings and paste an API key   2. Tap Start Camera  
    3. Align the screen inside the box

  
  

  
The start tap is required once by the browser to allow the
    camera and voice. Voice answers use your phone's built-in speech.
